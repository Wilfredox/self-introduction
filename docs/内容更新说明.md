# 内容更新说明

这个站点现在是纯 GitHub 静态作品集。

它的意思是：

- 网站里没有管理员后台
- 不在站内上传作品
- 不在站内登录后修改内容

更新方式改成：

1. 在 GitHub 里编辑内容文件
2. 提交后重新发布静态站

当前默认发布目标是：

- GitHub 仓库 Pages

如果后续绑定自定义域名，
仍然沿用现在的 `HashRouter` 和 `404.html` 跳转策略。

## 现在主要改哪里

当前主要内容都在：

- `src/content/site.ts`
- `src/content/projects.ts`

你以后最常改的是这几类内容：

### 1. 个人信息

`src/content/site.ts` 里 `siteProfile` 这一段可以改：

- `name`
- `tagline`
- `contacts`

### 2. 简历信息

`src/content/site.ts` 里 `resumeContent` 这一段可以改：

- `title`
- `summary`
- `downloadLabel`

### 3. 作品内容

`src/content/projects.ts` 里的每个作品对象都可以改：

- `title`
- `excerpt`
- `period`
- `description`
- `role`
- `highlights`
- `notes`
- `links`
- `imageCaptions`
- `downloadFileName`
- `downloadLabel`
- `downloadText`
- `downloadMimeType`

## 如果只想改文字，不想碰结构

优先只改这些字段的内容：

- 标题
- 摘要
- 描述
- 链接
- 联系方式

先不要随便改：

- `id`
- `slug`
- `assetId`

因为这些字段更像程序内部识别用的键。

## 当前简历和图片说明

当前仓库现在已经开始混合使用两类资源：

- 代码生成的占位封面 / 占位截图
- 放在 `public/` 里的真实简历与真实项目附件

如果后面你要继续替换成更多真实图片 / 真实 PDF / 真实 PPT / 真实 Word，
建议继续整理到：

- `public/images/...`
- `public/resume/...`
- `public/projects/...`

这样以后在 GitHub 上改内容会更轻松。
