第三轮 / 真实联调与视觉落地

这一轮不再讨论新方向，也不再扩写新功能。设计的任务变成两类：给 React 页面持续提供唯一视觉基线，以及把联调中最容易跑偏的长文本、移动端和 PDF 预览边界补成明确规则。

A 版唯一 公开页继续只认 A 版基线
React 视觉贴合 设计稿不再替代正式入口

本轮重点

  • 补清超长文本、移动端间距层级、PDF 预览容器边界等第三轮细节规则。

01 / 第三轮角色

第三轮先贴视觉，再把易跑偏的细节钉住。

页面范围和首页方向继续冻结。设计在这一轮不再补新页面，而是给联调中的真实页面提供持续审稿基线和边界说明。

公开页审稿重点

  • 首页顶部信息层级和作品入口优先级
  • 拼贴卡默认态 / hover / 聚焦态的一致性
  • 详情页主内容区与侧栏的信息轻重关系
  • 简历页“先看，再下载”的动作顺序

第三轮细节规则

  • 超长标题、摘要、说明文案如何收束
  • 移动端降级后的间距和信息层级
  • PDF 预览容器的边界、留白和空态
  • 保留状态说明，不新增新交互概念

继续冻结内容

  • 首页方向仍然只有 A 版
  • 首页主链接继续取 `links[]` 第一项
  • 拼贴布局位置继续由前端静态控制
  • 不新增分类、搜索和后台可编辑拼贴布局

03 / 设计标注

第三轮继续执行的视觉口径

这些规则会同步写进 `docs/交付/UI设计交付.txt`，也是前端第三轮贴视觉细节时的基线，不再靠口头约定。

字体与层级

  • 首页主标题：48px - 72px，字距 0
  • 页面标题：32px - 44px
  • 正文导语：18px / 1.7
  • 注释和标签：13px - 14px

颜色与材料

纸白
墨黑
橄榄绿
锈橘

内容占位

  • 作品标题建议 8 - 16 个中文字符
  • 摘要建议 36 - 80 个中文字符
  • 联系方式建议控制在 3 条以内
  • 首页第一屏不堆长说明，优先给作品入口

长文本收束

  • 首页卡片标题最多 2 行，超出用省略收束
  • 首页放大态摘要优先控制在 3 - 4 行可读范围
  • 详情页长段落按小节切开，避免首屏整块压迫

移动端层级

  • 首页题头改纵向堆叠，姓名始终先于介绍和联系方式
  • 详情侧栏信息下沉到正文后，不与主图并列争抢首屏
  • 简历动作区先于预览出现，但视觉权重要低于预览本体

PDF 预览边界

  • 预览区必须有稳定框体和留白，避免像普通图片区
  • 页与页之间保留明确分隔，不能贴成连续长图
  • 加载失败时也保留框体，用空态文案替代空白塌陷
